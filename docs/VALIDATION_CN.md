- 音效提交检查：使用实际适配代码和官方 Ogg 解析器；验证重复点击不排队、忙时丢弃、配置页面可播放、恢复唤醒、队列超时和 AI 优先。
- 退出对话检查：使用实际 CloseChat 方法，验证主线程调度、停止收音、清空播放队列、关闭通道，以及连接中 / 已断开时的状态变化。
- 屏幕方向检查：实际 CO5300 初始化寄存器与原 Arduino 正常方向一致；逐一核对 481×481 组原始触摸坐标，并验证四向显示与触摸路径。已取消合并版中额外硬件镜像。 根据用户明确的“三颗按键朝上时画面向右倒 90°”反馈，在最终刷屏层增加固定向左 90° 补偿，原始触摸做逆变换；覆盖 4 种已保存 / 自动逻辑方向，保留既有 NVS 设置。实际刷屏函数以非对称 2×3 色块和明确的原生坐标 / 像素序列检查，按键朝上视角的四角及 480×480 个触摸点全部对齐。
- 触摸读取检查：使用 CST9217 1.0.4 的实际读包 / 解码函数及 ACK 门控模拟控制器；保留 `D0 00 AB`，有效松手去抖 80ms，无效 / 缺失报告不会立即拆断按住；覆盖一秒间歇触点报告及连续失联 1.2 秒后的有界释放、读失败 / ACK 失败 / 异常包与恢复。控制器组件源码未改动。
- 设置按钮检查：四个方向逐一点击骰子数量 / 面数加减、保存 / 取消、流沙页面点击开始 / 暂停、重置、秒数调整 / 预设 / 保存 / 返回，以及玩家人数调整 / 预设 / 保存 / 返回；验证按钮按下反馈，并使用不同停留时长、松手后更换位置的输入序列。
- 流沙新交互检查：取消独立开始按钮，点击沙漏 / 数字 / 背景开始、暂停、继续及到时重开；底部仅有一个宽 272 像素的重置按钮，左 / 中 / 右点击均只重置、不启动。长按 2 秒打开设置，允许距起点 24 像素以内抖动，拖动取消；打开设置后的松手不触发其他操作。覆盖四个逻辑方向、短于 2 秒的停留、设置保存 / 返回及 Key3 层级。设置按钮原有长按连调逻辑保留。
- 流沙事件：主界面不再使用 `LV_EVENT_CLICKED` 驱动切换 / 重置；统一处理按下、持续按住、松手与失焦，一次手势只产生一个动作。新的按下必须距上次切换至少 500ms；按下时仍在间隔内，即使稍后松手也不接受该次短按。长按 2000ms 优先设置并消费松手，包含冷却间隔内开始长按、UI 延迟到松手才处理、拖动取消、计时回绕及重复松手。四向真实 LVGL 输入注入无效包、假松手和稀疏报告，长按仍只打开一次设置，不切换计时。
- 重置与坐标：保留一个宽 272 像素的新重置控件，无额外 6 像素扩展热区；按下与松手区域必须一致，忽略冒泡的子事件。四向检查沙漏右侧和按钮四边外侧不会重置剩余时间。实际坐标错位通过原始触点三点校准修正，未凭反馈猜测更改固定屏幕方向。
- 校准：真实 LVGL 校准覆盖层不依赖现有逻辑触摸坐标，暂时使用逻辑方向 0，完成 / 取消后恢复原方向；覆盖原先手指未松开、三点求解、无效点重试、保存失败保留旧映射。模型覆盖八种轴交换 / 镜像、采样网格点、退化矩阵、非法记录和 NVS 提交失败；新 `orbit-touch` 命名空间保存矩阵。首次进入流沙时没有记录自动提示；按住 Key3 三秒可重做，单击 Key3 取消。
- 触摸诊断：`STATUS` 保留 `ORBIT TOUCH`，本版标识 `sand_stable_v4`。实板触摸位置、真实报告节奏和交互效果仍需烧录后校准并确认，主机模拟不代表实板已恢复。
- Key2 绑定检查：执行实际按键注册函数，不依赖单击分类事件，验证按下反馈、松开触发及连续按三次；没有保存网络时发出重新显示配网 UI 的请求。
- 网络检查：实际 Key2 联网代码在主机模拟中覆盖单任务去重、已联网只校时、配网退出重试、空配置提示和任务创建失败；原样转发小智联网事件。
- Wi-Fi 优先顺序检查：执行本地组件的实际扫描选择和成功连接排序代码，覆盖较弱的最近网络优先、同名热点信号排序、信道变化全扫描、其他保存网络回退和重复成功不写 NVS。
- NTP 检查：执行实际校时逻辑，验证回应后确认成功、30 秒超时、60 秒重试、断网重连重新校时、初始化失败和计时回绕。
- 网络中文提示：真实 LVGL 9 字形、布局、显示时长和不拦截触摸检查通过。
- 烧录包检查：SHA-256、长度、固定地址、NVS 保护范围和实际二进制分区表通过。
- C/C++ 格式、Git 差异空白检查和仓库 Markdown 检查通过。
